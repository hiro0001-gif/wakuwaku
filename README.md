# わくわくB&S Webサイト 修正版v4

## 確認方法

ZIPを展開し、フォルダ内の `index.html` をダブルクリックするとブラウザで確認できます。

## ページ構成

- `index.html`：トップ・施設紹介・お知らせ
- `activity.html`：できること
- `price.html`：料金・サービス
- `reservation.html`：会員予約
- `access.html`：アクセス・仮案内図
- `css/style.css`：全ページ共通のデザイン
- `js/main.js`：スライド、お知らせ詳細、予約枠の処理
- `images/`：ロゴ・メイン画像・仮案内図

## 営業案内

- 営業日：木曜日・金曜日・土曜日
- 営業時間：9:00〜18:00
- 年末年始等、休日がある場合は事前に告知

## 予約機能

開始時間は9:00〜17:00です。利用時間は、営業時間内に収まる場合のみ「1時間」「3時間」「1日（18:00まで・4時間以上）」から選べます。各1時間枠の予約上限は8人です。

この完成ファイルでは予約数をブラウザの `localStorage` に保存します。残席は同じ端末・同じブラウザ内だけで共有されます。本番運用では、複数端末で予約を共有するデータベースと、会員ID・電話番号を確認するサーバー側の処理が必要です。
