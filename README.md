# わくわくB&S Webサイト

健康コミュニティ施設「わくわくB&S」の5ページ構成Webサイトです。

## ファイル構成

- `index.html`：トップページ
- `activity.html`：できること
- `price.html`：料金・サービス
- `reservation.html`：会員予約
- `access.html`：アクセス・仮案内図
- `css/style.css`：全ページ共通のデザイン
- `js/main.js`：メニュー、スライドショー、予約人数の処理
- `images/`：ロゴと画像

## 確認方法

ZIPを展開し、フォルダ内の`index.html`をダブルクリックするとブラウザで確認できます。

## 予約機能について

このファイル版では、予約数をブラウザの`localStorage`に保存します。そのため、残席数は同じ端末・同じブラウザ内でのみ共有されます。

実際に複数の利用者がスマートフォンやパソコンから予約する場合は、データベースとサーバー側の予約処理を追加してください。また、会員ID・登録電話番号の照合もサーバー側で行う必要があります。
